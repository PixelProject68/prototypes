# mooon – вид с места

Прототип выбора мест с режимом «Вид с места»: 2D-схема зала превращается в 3D-зал, камера пролетает в выбранное кресло, из кресла можно осмотреться и пересесть.

Зал – Зал 3 mooon+ (ТРК Minsk City Mall), раскладка снята с mooon.by/hall, сеанс «Эбенезер» 25.11 в 19:00. Занятость демонстрационная: центр зала свободен, чтобы посмотреть вид с центральных мест. В плашке «Пространство» для короткой подписи стоит Dana Mall. Экран рассчитан на 2560×1290, на других размерах страница масштабируется целиком.

## Как открыть

- Ссылка GitHub Pages: папка открывается как есть, сборка не нужна.
- Локально: любой статический сервер из этой папки, например `python3 -m http.server`, затем `http://localhost:8000`. Открывать файлом (`file://`) нельзя: браузер не загружает ES-модули без сервера.
- Esc – выйти из вида с места.

## Данные зала

`js/data.js`, массив `ROWS`: для каждого ряда список кресел `[x, ширина]` в пикселях SVG-схемы mooon.by (ширина схемы 816) и строка статусов (`F` – свободно, `T` – занято). Ширина больше 30 – диван, иначе кресло. Номера мест считаются слева направо, у дивана один номер, как на mooon.by.

Чтобы подключить живые данные, достаточно собрать `ROWS` из ответа API схемы зала: 3D-зал, схема и мини-схема строятся из одного массива.

Перевод в метры: `K = 0.03125` м на пиксель схемы, первый ряд в `ROW_Z0` м от экрана, шаг рядов `ROW_STEP`, подъём амфитеатра – `floorOf(ряд)`.

## Как устроен переход

Главная идея: 2D-схема – это проекция 3D-зала сверху. Кнопки мест ставятся туда, куда камера «сверху» проецирует каждое кресло (`buildMap` → `project`), поэтому при смене схемы на 3D ничего не сдвигается.

| Функция (`js/app.js`) | Что делает |
|---|---|
| `computeTop` | подбирает камеру сверху так, чтобы зал занял сцену с отступами `MAP_PAD` |
| `buildMap` | ставит кнопки мест, номера рядов и дугу экрана по проекции |
| `openPreview` | 3D проявляется под схемой (450 мс), схема гаснет (380 мс), сцена расширяется, полёт 2700 мс |
| `flightPose(t)` | позиция камеры на кривой Безье от вида сверху к глазам зрителя, поворот, угол обзора 18° → 46° |
| `morph(t)` | синие свободные места перекрашиваются в обивку, гаснет верхний свет, включается свечение |
| `povPose` | вид из кресла с поворотом головы (`yaw`, `pitch`) |
| `hop` | перелёт в другое кресло по дуге за 1300 мс |
| `closePreview` | голова возвращается прямо (380 мс), обратный полёт 2400 мс, схема проявляется |

Холст 3D всегда шириной развёрнутой сцены (2080), видимая часть задаётся `camera.setViewOffset` – так сцена расширяется без пересоздания буферов и без рывков.

## Для отладки

`window.__dbg.pose(t)` – кадр полёта в точке `t` от 0 до 1, `window.__dbg.pov(yaw, pitch)` – вид из кресла с заданным поворотом.

## Что в прототипе условно

- 3D-зал собран автоматически по схеме: ряды, подъём, экран и проходы правильные. Интерьер – по фото зала mooon с реклайнерами: чёрная кожа со строчкой ромбом, консоли со столиками и жёлтыми номерами, стены из ромбовидных панелей, фронт ступеней с прорезями, ковролин. Фото этого же зала или нет – уточнить; геометрия кресел упрощённая.
- На экране заглушка с названием фильма; в рабочей версии сюда ставится трейлер (видеотекстура).
- Кнопка оплаты показывает уведомление, оплаты нет.
